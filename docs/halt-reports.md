# Автоматические отчёты HALT

При локальной остановке боя или получении HALT от другого игрока мод создаёт
папку `reports/halt_...` рядом с текущим логом, то есть внутри каталога логов.
В окне остановленного боя отображаются объяснение и кнопка `Copy report folder`.

Содержимое папки:

- `report.txt`: протокол, дата сборки, роль игрока, бой, ход, исходная причина,
  последние 32 действия из кольца логов и недавние диагностические сообщения.
- `local.log`: копия локального лога на момент обновления отчёта.
- `peer_N.log`: полученный хостом хвост лога соответствующего игрока
  (не более 768 КиБ). В отчёте указано, получен ли каждый ожидаемый лог.

Запрос логов при HALT обходит обычное ограничение частоты запросов при неполадках.
Хост добавляет полученные логи в последний отчёт в течение двух минут после HALT.
У клиента сохраняется собственный отчёт; общая подборка логов находится у хоста.
При разрыве соединения лог друга может остаться недоступным.

Диагностический раздел содержит недавний контекст, включая предыдущие ходы.
Сравниваемые поля котов помогают увидеть расхождение, но сами по себе не
устанавливают название отсутствующего эффекта или причину его исчезновения.
Для разбора следует передавать всю папку отчёта с хоста.

Проверка без игры: `test_peerlog` создаёт настоящий отчёт во временной папке,
проверяет локальный лог, действие, различие котов и добавление входящего лога
друга. Проверку с реальным сетевым HALT нужно проводить в игре.
